# WAYO — прототип с лентой мест

Откройте `index.html` в браузере. Установка и сборка не нужны.

В приложении:
- Лента из шести публикаций о местах Санкт-Петербурга с большими фотографиями, подробными историями, адресами и советами.
- Поиск по названию, категории и полному тексту, фильтры по интересам.
- Карточка места, избранное и боковая коллекция сохранённых мест.
- Сборка маршрута, изменение порядка и удаление остановок, скачивание плана.
- Сохранение избранного и маршрута в браузере на этом устройстве.

Все фотографии показывают соответствующие локации и хранятся локально в `assets/`. Авторы, источники и лицензии доступны в каждой публикации и в `PHOTO-CREDITS.md`. Фотографии уменьшены Wikimedia Commons и визуально кадрируются в интерфейсе. У исторических снимков облик места может отличаться от сегодняшнего. Источники описаний указаны в публикациях; перед поездкой следует уточнить режим посещения.

Маршрут строится в порядке сохранения, автоматической оптимизации и расчёта расстояний пока нет. Карта условная. Оплата и подписка не подключены.

Для локального просмотра через сервер из папки `app`: `python3 -m http.server 4173 --bind 127.0.0.1`, затем откройте http://127.0.0.1:4173.
