# WAYO

WAYO помогает превратить сохранённые идеи о местах в маршрут прогулки по Санкт-Петербургу на один день.

Добавьте музеи, парки, достопримечательности, кафе и рестораны через поиск или со скриншота. Выберите стартовую точку, время поездки, темп и способ передвижения — приложение составит расписание посещений и покажет путь на карте.

## Возможности

- **Место со скриншота.** Нейросеть читает названия и адреса на изображении. Запрос можно исправить, а найденное место — проверить перед добавлением.
- **Поиск реальных мест.** Названия, адреса и категории поступают из 2ГИС. Разные филиалы выбираются отдельно; повторные места не добавляются.
- **Программа на день.** Планировщик сравнивает время перемещений через 2ГИС, учитывает посещения, еду, свободное время и возвращение к старту.
- **Способы передвижения.** Пешком, на автомобиле или пешком с общественным транспортом.
- **Еда отдельно от достопримечательностей.** Сохранённые заведения рассматриваются как варианты остановок на еду. Кофебрейк появляется только с выбранным заведением.
- **Карта и расписание.** Порядок посещений, время в пути, остановки и места, не вошедшие в маршрут.
- **Черновик поездки.** Выбранные места и настройки сохраняются в браузере на устройстве.

## Как пользоваться

1. Найдите места по названию или нажмите **«Добавить со скриншота»**.
2. Проверьте адрес и добавьте нужный объект в коллекцию.
3. Выберите старт, дату, начало и окончание дня, темп и транспорт.
4. Нажмите **«Составить маршрут»** и просмотрите программу и карту.

## Локальный запуск

Нужен **Node.js 22 или новее**. Установка дополнительных пакетов не требуется.

```sh
git clone https://github.com/glollutsik/wayo.git
cd wayo
cp .env.example .env
```

Заполните `.env` собственными ключами:

| Переменная | Назначение |
|---|---|
| `TWOGIS_API_KEY` | Поиск мест и расчёт путей в 2ГИС |
| `TWOGIS_MAP_KEY` | Отображение карты 2ГИС |
| `OPENROUTER_API_KEY` | Распознавание через бесплатные модели OpenRouter (основной вариант) |
| `OPENROUTER_MODEL` | `openrouter/free` или модель с суффиксом `:free`; платные модели запрещены |
| `GROQ_API_KEY` | Чтение названий и адресов через Groq (дополнительный вариант) |
| `GROQ_MODEL` | Модель Groq; по умолчанию `qwen/qwen3.8-27b` |
| `SCREENSHOT_PROVIDER` | `auto` выбирает OpenRouter, затем Groq, затем Gemini по наличию ключей; также можно явно задать `openrouter`, `groq` или `gemini` |
| `GEMINI_API_KEY` | Ключ для сохранённого варианта с Gemini |
| `GEMINI_MODEL` | Модель Gemini; значение по умолчанию указано в `.env.example` |

Затем запустите:

```sh
node server.mjs
```

Откройте **http://127.0.0.1:4174/**. После изменения ключей перезапустите сервер. На хостинге ключи задаются через переменные окружения. `.env` не публикуется в репозитории.

Это приложение с сервером Node.js: простого открытия HTML или размещения только на GitHub Pages недостаточно.

## Технологии и данные

Интерфейс — HTML, CSS и JavaScript; сервер — Node.js. 2ГИС отвечает за места, карту и перемещения, OpenRouter, Groq или Google Gemini — за извлечение читаемых названий и адресов из скриншота.

Изображение отправляется в выбранный сервис распознавания (по умолчанию OpenRouter при наличии ключа). Автоматических повторов и переключения на другой сервис после ошибки нет. Приложение не сохраняет скриншоты на сервере. Ключи OpenRouter, Groq, Gemini и серверного API 2ГИС остаются на сервере; картографический ключ передаётся браузеру по назначению сервиса. Локальный кеш маршрутов находится в `data/` и исключён из Git.

## Ограничения прототипа

- Санкт-Петербург, один день, до 20 сохранённых мест.
- Распознавание может ошибаться: проверяйте названия, адреса и филиалы. Поиск по визуальному сходству фотографии без читаемого текста не реализован.
- Время посещений приблизительное. Часы работы, билеты, очереди и парковка не учитываются.
- Глобально оптимальный маршрут не гарантируется. Доступность транспорта, данные и квоты зависят от внешних сервисов.
- Прототип выполняет один расчёт маршрута одновременно.

## Размещение на Render Free

В репозитории есть `render.yaml` с бесплатным планом и `.node-version` для Node.js 24.

1. В Render создайте Blueprint из этого репозитория либо Web Service с веткой `main`.
2. Выберите **Free** и регион Frankfurt. Build Command: `node --check server.mjs`; Start Command: `node server.mjs`.
3. В закрытых переменных окружения укажите `TWOGIS_API_KEY`, `TWOGIS_MAP_KEY`, `OPENROUTER_API_KEY`. Файл `.env` загружать в репозиторий не нужно.
4. Для ручного Web Service задайте `HOST=0.0.0.0`. Порт берётся из `PORT`, который предоставляет Render. Health Check Path: `/healthz`.
5. При ограничении картографического ключа по домену разрешите выданный адрес `*.onrender.com` конкретного приложения в настройках 2ГИС.

Проверка `/healthz` не обращается к внешним API. После простоя бесплатный сервер может запускаться с задержкой. Локальный кеш маршрутов на Free не является постоянным хранилищем и может теряться при перезапуске. Квоты сервисов распознавания и 2ГИС действуют отдельно от тарифа хостинга.

## Проверки

```sh
node --test tests/*.test.mjs
```

Тесты используют искусственные данные и подменённые ответы внешних сервисов, не расходуя реальные квоты API.
